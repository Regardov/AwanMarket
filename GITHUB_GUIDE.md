# Как пользоваться AwanMarket

## Как открыть магазин

После запуска проекта откройте в браузере <http://localhost:8080>. На главной странице находятся
продукты, цены и кнопки добавления в корзину.

## Как зарегистрироваться

1. Нажмите **Войти** в правом верхнем углу.
2. Выберите ссылку **Нет аккаунта? Зарегистрироваться**.
3. Введите имя, email и пароль длиной не менее 8 символов.
4. Нажмите **Зарегистрироваться** — вход выполнится автоматически.

Прямая ссылка для локального запуска: <http://localhost:8080/register>.

## Как войти в админ-панель

1. Откройте файл `.env` на сервере.
2. Посмотрите значения `ADMIN_EMAIL` и `ADMIN_PASSWORD`.
3. Войдите с этими данными на странице <http://localhost:8080/login>.
4. После входа откройте <http://localhost:8080/admin> или нажмите **Админка** в меню.

В админ-панели можно добавлять и редактировать продукты, смотреть пользователей, заказы и
выручку. Перед размещением в интернете обязательно замените стандартный пароль администратора
и `SECRET_KEY` в `.env`.

## Как скачать мобильное приложение

1. Откройте вкладку **Actions** в репозитории GitHub.
2. Выберите workflow **Build AwanMarket clients**.
3. Нажмите **Run workflow**, укажите публичный HTTPS-адрес backend в поле `api_base_url` и
   дождитесь завершения сборки.
4. Откройте завершившийся запуск и в разделе **Artifacts** скачайте `AwanMarket-Android`.
5. Распакуйте ZIP и установите файл `app-release.apk` на Android.

Android может попросить разрешение на установку APK из браузера или файлового менеджера.
iOS-сборка не включена: для неё требуется Apple Developer Account и подпись приложения.

## Как скачать desktop-приложение

1. Откройте **Actions → Build AwanMarket clients**.
2. Запустите workflow или откройте уже завершившийся запуск.
3. В разделе **Artifacts** скачайте `AwanMarket-Windows`.
4. Распакуйте архив и запустите `AwanMarket.exe`.

По умолчанию desktop-клиент подключается к `http://127.0.0.1:8080`. Для другого сервера перед
запуском задайте переменную окружения `AWANMARKET_API_URL`.

## Запуск всего проекта через Docker

```powershell
Copy-Item .env.example .env
docker compose up --build
```

Swagger API будет доступен по адресу <http://localhost:8080/docs>.
